Adaptive Data Weighting for Neuro-GRAPE
A practical, human-readable guide to GroupDRO and DOGE
Research note for the Neuro-GRAPE project
October 2026
Abstract
Neuro-GRAPEaimstolearnusefulrepresentationsfromdifferentkindsofneuraldata, including
EEG, MEG, and fMRI. These sources differ in sensors, spatial and temporal resolution, noise, and
sample availability. A model trained to do well on average can still perform poorly on one source
or subgroup. This note explains two ways to adjust training emphasis: Group Distributionally
Robust Optimization (GroupDRO), which directly focuses on the group with the highest loss, and
DOGE (Domain Reweighting with Generalization Estimation), which estimates which domains’
gradients help a chosen generalization objective. The methods are related because both adjust
data weights, but they answer different questions. The mathematical sections give simplified,
implementation-oriented formulations; exact details should be checked against the original papers
before reproducing a published method.
1 Start with the practical problem
Imagine a training set containing EEG, MEG, and fMRI examples. If the model sees many easy
EEG examples and fewer difficult fMRI examples, its average training loss may look good while its
fMRI performance remains weak. A single average can hide that failure.
Neuro-GRAPE therefore needs to track both:
• A verage performance: how well the model performs over the evaluation population overall.
• Group performance: how well it performs separately for each meaningful group, such as
modality, subject, session, or a predefined data source.
A group should be defined from reliable metadata where possible. Clusters made from embeddings
can be useful exploratory partitions, but should not automatically be interpreted as biologically
meaningful neural states.

3 Method 1: GroupDRO
3.1 Intuition
GroupDRO asks: What if we optimize for the group that is currently doing worst, rather than letting
easy or large groups dominate the average? It raises the influence of groups with high loss. The goal
is to reduce worst-group loss, not merely the overall average.

3.3 A tiny example
Suppose the group losses areLEEG = 0.3, LMEG = 0.5, andLfMRI = 0.9. GroupDRO should increase
the relative weight of fMRI because it has the highest current loss. If that loss reflects noisy labels or
a broken preprocessing path, however, upweighting it may be harmful; data quality and group sizes
must be checked.
4 Method 2: DOGE
4.1 Intuition
DOGE asks a different question:Which training domain appears to help the chosen generalization
objective when we look at how its gradient interacts with gradients from other domains? It does not
simply focus on whichever domain has the highest loss. It uses a smaller proxy model to estimate
domain weights, averages those weights over proxy training, and then uses the estimated mixture to
train a final model.

4.3 A simple interpretation
If gradients from one domain tend to align with gradients that improve the selected objective, DOGE
may assign that domain more sampling weight. But gradient magnitude and alignment can be
affected by noise, architecture, scaling, and batch composition. The learned weights should be treated
as optimization diagnostics, not as evidence of shared neural coding.

6 How this maps to Neuro-GRAPE
For Neuro-GRAPE, groups could initially be defined by modality (EEG, MEG, fMRI), provided
the data and evaluation setup support that comparison. Other possible groups include subject,
session, task, or a prespecified acquisition source. Each choice answers a different question, so group
definitions should be fixed before looking at final test performance.
A practical experiment should:
1. Train a baseline with a fixed, documented sampling mixture.
2. Train a GroupDRO model using per-example or per-group losses in the actual gradient objective.
3. Optionally train a DOGE-style mixture baseline with a proxy model and a separate final-model
run.
4. Keep architecture, data splits, preprocessing, compute budget, and evaluation metrics comparable.
5. Tune hyperparameters using training/validation data only; evaluate the held-out test set only for
final reporting.
6. Repeat with multiple random seeds when feasible and report uncertainty, not just one score.
7 Metrics to report

gap between best and worst groups. For a loss where lower is better:

8 Scientific and engineering guardrails
• EEG, MEG, and fMRI in this pilot are independent recordings. Shared stimulus identity supports
semantic correspondence; it does not establish synchronized neural time series.
• Join records by stable identifiers such assample_id or validated stimulus_id, never by row
order.
• Fit preprocessing statistics and clusters on training data only; assign validation/test examples
using the already-fitted transforms.
• A cluster is an exploratory partition unless independently validated; do not label it a biological
neural regime based on silhouette score alone.
• The 20-stimulus pilot is useful for checking code paths and interfaces, but it is too small to
establish robust scientific conclusions.
• Do not call a run genuine GroupDRO unless group-weighted losses affect backpropagation and
model parameters actually change.
